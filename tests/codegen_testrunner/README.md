# Playwright code generation

`codegen.spec.ts` contrasts a manually written browser test with test steps resembling code generated by Playwright's recorder.

## Generate a recording

From the repository root:

```bash
npx playwright codegen https://demowebshop.tricentis.com/
```

Interact with the opened page. The inspector records navigation, actions, and assertions and suggests locators. Copy the useful steps into a maintained spec, then simplify and strengthen them.

## Simple test example

```ts
test('home page shows the store name', async ({ page }) => {
  await page.goto('https://example.test')
  await expect(
    page.getByRole('link', { name: 'Example Store' })
  ).toBeVisible()
})
```

Generated code is a starting point, not a finished test. Review locator uniqueness, add assertions that verify behavior, replace brittle selectors with accessible locators, remove unnecessary waits, and use stable test data. `codegen.spec.ts` also demonstrates locating text and images by alternative text.

Run the example:

```bash
npx playwright test tests/codegen_testrunner/codegen.spec.ts
```
